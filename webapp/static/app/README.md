# Приложение (PWA) — /app

Отдельный раздел. Мини-апп (`/`), сайт (`/site`, `/static/*.html`) и бот не затрагиваются.
Вход общий с сайтом (`/api/site/login`, токен `cw_token`), данные — из тех же `/api/*`.

Файлы: `app.html` (интерфейс), `manifest.webmanifest`, `sw.js` (service worker, только `/app*`), иконки.
Маршруты добавлены в `webapp/server.py` блоком «Мобильное приложение (PWA)».
Этап 1: вход, главная, машины, касса, отчёты за смену — только чтение.

Этап 2: добавление машины (кузов, услуги, мойщик, оплата вкл. раздельную, телефон, своя сумма), карточка машины: смена статуса и удаление. Используются POST /api/car, PATCH/DELETE /api/car/{branch}/{num}.

Этап 3: открытие и закрытие смены на главной (для админа/владельца), сверка наличных при закрытии. POST /api/openday, /api/closeday.

Этап 4: записи (выбор даты на неделю вперёд, новая запись по боксам, смена статуса, удаление). GET/POST /api/bookings, PATCH .../status, DELETE. Запись с услугами на сегодня сама создаёт машину в кассе (логика сервера).

Этап 5: клиенты и лояльность. Главная → «Клиенты»: список с поиском (имя, телефон, авто), карточка клиента (визиты, потрачено, последние визиты, звонок), правка имени и машин, постоянная скидка (только админ/владелец). GET /api/clients, GET/PUT /api/clients/{phone}, PUT/DELETE /api/clients/{phone}/discount.
Главная → «Скидки»: скидки за смену (список, добавление по машине, удаление), быстрая кнопка из карточки машины. POST /api/loyalty, DELETE /api/loyalty/{branch}/{idx}.
В форме новой машины: подсказки клиентов из базы (GET /api/clients/search) по телефону или имени; при выборе клиента с постоянной скидкой итог пересчитывается автоматически (сумму можно поправить вручную), имя клиента передаётся в кассу.

Этап 6: сотрудники и график. Главная → «Сотрудники». Вкладка «График»: неделя по дням для каждого мойщика, листание недель, отметка «сегодня на смене»; админ по тапу меняет график (N рабочих / M выходных от даты), сбрасывает его, добавляет и удаляет сотрудников. GET /api/schedule/week, POST /api/schedule, DELETE /api/schedule/{branch}/{name}, POST /api/workers, DELETE /api/workers/{branch}/{name}.
Вкладка «Зарплата» (только админ/владелец): сводка за сегодня/неделю/месяц по всем ролям сотрудника, карточка с разбивкой по ролям и дням. GET /api/employees-stats, GET /api/employee-stats.
Авансы не включены: ручек /api/advance в server.py нет (на сайте кнопки аванса тоже не работают, аванс выдаётся только через бота).

Этап 7: расширенные отчёты. Вкладка «Отчёты» → Смена / Неделя / Месяц / Архив.
Смена: итоги, способы оплаты, популярные услуги, PDF и XLSX за смену. Неделя (GET /api/reports/week): выручка, график по дням, среднее за день, лучший день, средний чек, зарплаты мойщиков, список дней. Месяц (GET /api/reports/month): выбор месяца и года, выручка, зарплаты сотрудников по неделям. Архив (GET /api/archive): последние 30 смен, по нажатию — PDF/XLSX (GET /api/reports/pdf|xlsx; на телефоне открывается меню «Поделиться»).
Месяц считается только по закрытым сменам (так работает сервер), неделя включает текущую смену.
Дальше: оболочка для установки из магазинов (Capacitor/TWA).

Вход: экран в стиле приложения (синий блок + стеклянная карточка): пароль, имя, должность, филиал.
Пароли: SITE_PASSWORD — для мойщиков; SITE_ADMIN_PASSWORD (новая переменная, webapp/auth_web.py) — для админа и владельца. Пока SITE_ADMIN_PASSWORD не задана, работает один общий пароль, как раньше. Действует и на сайте, и в /app.

Этап 8 (редизайн навигации): нижнее меню — Главная · Машины · «+» · Касса · Настройки (вместо «Отчёты»).
Главная — дашборд: касса, смена, выручка/машины/расходы, выручка за 5 дней, кто на смене, зарплаты, машины в работе.
Настройки: Записи, Клиенты, Скидки, Сотрудники, Отчёты, Филиалы, выход. Подэкраны возвращают в «Настройки».
Филиалы (как на сайте): сводка по каждому филиалу (выручка, машины, сотрудники, тренд за 5 дней), переключение активного филиала, назначение администратора (владелец). GET /api/branches/summary, /api/users, /api/workers, POST /api/branch-admin. Кнопка филиала в шапке открывает этот экран.
Единый набор SVG-иконок, скелетоны загрузки, анимация переходов, фильтр на вкладке «Машины». Исправлен конфликт CSS-класса тега «в работе» с кнопками меню. Кэш SW: cw-app-v6.
